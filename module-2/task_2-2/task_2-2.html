1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants brukes når en verdi ikke skal endres, variables kan brukes for verdier som kan/skal endres. Variabler kan gjøres til constants og vice versa.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentes bestemmer utregningsrekkefølgen i et uttrykk.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. Man kan bruke kommandoen .toFixed for å bestemme antall gitte desimaler.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Man kan bruke "===" for å sjekke om de er like eller "!==" for å sjekke om de er ulike.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators returnerer bolske verdier. Man kan f.eks. bruke betingelser (if, else if, else) for å sjekke om de er true eller false.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() funksjonen returner et tilfeldig tall mellom 0 og 1. Man kan gange opp hvis du vil ha en større skal med mulige tall.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus gir en resterende verdi etter man deler et tall som ikke går opp som helt tall i den gitte divisjonen. Det kan f.eks. brukes hvis du vil finne hvor mange hele uker det er i et antall dager.
